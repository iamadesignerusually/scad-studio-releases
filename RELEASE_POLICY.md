# Public release policy

This repository is the public downloads and announcements surface for SCAD Studio, not the development repository. Release artifacts must be approved as discrete versions; a green build alone is insufficient.

Before publishing a release:
1. Human owner signs off version, changes, target platform, artifact hashes, code-signing identity, dependency ledger, binary license, privacy notice and consumer/legal obligations.
2. Validate no proprietary source, user model files, tokens, signing material, Bambu LAN credentials or accidental debug files are included.
3. Verify downstream component licenses (including GPL/AGPL obligations), security, distribution permissions, attributions and source offers.
4. iOS is distributed via Apple-approved mechanisms, not implied installable through GitHub. macOS bridge distribution requires a signed/notarized policy and documented updates.
5. Publish accurate release notes, binary hashes, limitations, supported firmware/printers and rollback/support information.
