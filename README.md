# SCAD Studio — Releases

Official public release channel for **SCAD Studio**, a native parametric CAD workspace for iPhone/iPad with optional Mac Print Bridge and Bambu Lab A1 integration.

**No public releases are available yet.** The project is under development. No preview build, signed binary, App Store link, or paid Pro offering is currently available.

## Distribution

- **iOS/iPadOS:** planned via Apple TestFlight/App Store after Apple Developer Program enrollment and review; GitHub binaries are not an equivalent iOS installation channel.
- **macOS Print Bridge:** potential signed/notarized download via this repository after release/security/legal review.
- **Source:** private and not distributed under an open-source license.
